These are the errors every Java beginner makes. Spot them early!
Forgetting the L suffix on long
long big = 3000000000; // ERROR! long big = 3000000000L; // Correct — note the L
Forgetting the f suffix on float
float price = 9.99; // ERROR! float price = 9.99f; // Correct — note the f
Integer overflow (silent bug!)
int max = 2147483647; max = max + 1; // Wraps to -2147483648 — no error!
Comparing decimals with ==
double a = 0.1 + 0.2; a == 0.3 // false! Use Math.abs(a - 0.3) < 0.0001
Losing data when casting (narrowing)
double d = 9.99; int i = (int) d; // i = 9, not 10 — decimal is cut off!
