# SDLC Images Directory

This directory contains PNG images for the SDLC tutorial content.

## ⚠️ IMPORTANT: How to Save Images

**When saving images, make sure the file name does NOT include ".png" extension twice!**

### ❌ WRONG Way (This creates double extension):
- File name in save dialog: `sdlc-complete-flow.png`
- Result: `sdlc-complete-flow.png.png` (WRONG!)

### ✅ CORRECT Way:
**Option 1:** Save without extension, then rename
- File name in save dialog: `sdlc-complete-flow` (no .png)
- Your image editor will add .png automatically
- Result: `sdlc-complete-flow.png` (CORRECT!)

**Option 2:** Save with extension, but check the file name
- If you see `filename.png.png`, rename it to remove one `.png`
- Or use the fix script below

### 🔧 Quick Fix Script

If you accidentally saved files with double extensions (`.png.png`), just **double-click** the file:
- **fix-image-names.bat** (in this folder)

This will automatically fix all image names for you!
